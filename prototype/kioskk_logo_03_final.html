How to export & use
1
Right-click this widget → Inspect Element
In your browser DevTools, find the <svg> tag for whichever logo you want. Right-click it → Copy → Copy outerHTML.
2
Paste into a .svg file
Open any text editor (even Notepad), paste the SVG code, save as kioskk-logo.svg. That's your vector file — infinitely scalable, zero quality loss.
3
For PNG (profile pics, app icons)
Open the .svg in Chrome → right-click → Save as image. Or drop it into Figma (free) and export at 1×, 2×, 3× for retina screens.
4
On your website
Drop the SVG inline in your HTML nav, or reference it as an <img src="logo.svg">. SVG in the nav means it's crisp on every screen, loads instantly, no HTTP request needed if inline.
5
For your agency
Send them the .svg file + this color palette:
Primary dark: #1a1a18
Brand red: #C84B2F
Accent red: #FF6B47 (on dark bgs)
Warm cream: #F5F0EB (icon bg)
Page bg: #FAFAF8
Font: DM Sans (wordmark) · Inter (UI)
