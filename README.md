# kioskk.me (Kioskk)

AI-powered micro-business storefront generator (Next.js App Router + Supabase + Claude).

## Status

This repo is being built toward the PRD in the task description:
- Setup flow at `/` to generate a business storefront at `/:slug`
- Storefront + PIN-protected dashboard at `/:slug`
- Super-admin panel at `/admin`

## Local dev

- Install: `npm install`
- Configure env: copy `env.example` → `.env.local`
- Run: `npm run dev`
